# ETF 모멘텀 백테스트

학습 구간에서 고른 '최적' 파라미터가 새로운 구간에서도 성과를 유지하는지 확인한 개인 실험입니다.
SSAFY AI 챌린지에서 검증 점수 과최적화를 경계했던 경험을 투자 전략 백테스트에 적용해 봤습니다.

체결 시점을 하루 미루는 것만으로 학습 1위 조합과 검증 결론이 바뀌었습니다. 최적 조합 하나의 성과보다는 가정을 바꿔도 결과가 유지되는지를 먼저 봐야 합니다.

## 실험 설계

| 항목 | 내용 |
|---|---|
| 데이터 | 국내 상장 ETF 7종의 2015~2025년 일별 수정주가 (yfinance) |
| 종목 | KODEX 200, TIGER 미국나스닥100, TIGER 미국S&P500선물(H), TIGER 유로스탁스50(H), KOSEF 국고채10년, KODEX 골드선물(H), KOSEF 미국달러선물 |
| 전략 | 매월 말 과거 L개월 수익률 상위 K개 ETF에 동일 비중 투자, 회전율당 거래비용 0.1% |
| 탐색 범위 | L = 1~12개월 × K = 1~3개, 총 36개 조합 |
| 학습 / 검증 | 2016~2021에서 샤프지수 1위 선택 → 2022~2025에 그대로 적용 |
| 체결 가정 | ① 당일 체결: 월말 종가로 신호 계산 후 같은 종가에 매매<br>② 익일 체결: 같은 신호로 다음 거래일 종가에 매매 |
| 벤치마크 | 7종 동일비중, 매월 리밸런싱 |
| 평가 지표 | CAGR, 샤프지수(무위험수익률 0 가정), MDD, 학습-검증 순위상관(Spearman), 부트스트랩 1,000회(독립 재추출, 6개월 블록 재추출) |

## 실험 결과

| | 당일 체결 | 익일 체결 |
|---|---|---|
| 학습 1위 조합 | 룩백 8개월, 상위 3개 | 룩백 7개월, 상위 3개 |
| 샤프지수 (학습 → 검증) | 1.38 → **0.96** | 1.34 → **1.33** |
| 벤치마크 검증 샤프 | 1.23 | 1.21 |
| 학습 1위의 검증 순위 | 36개 중 14위 | - |
| 벤치마크 대비 부트스트랩 우세 비율 (독립 / 블록) | 39% / 25% | 82% / 75% |
| 학습-검증 순위상관 | -0.21 | -0.14 |

- 당일 체결 1위였던 조합(8개월, 3개)을 익일 체결로 돌리면 샤프지수는 1.32 → 1.00이고, 검증 순위는 여전히 14위였습니다.
- 36개 조합의 검증 샤프 중앙값은 0.87로, 단순 동일비중 벤치마크보다 낮았습니다.

## 해석

1. **가정 민감도:** 체결 시점 하나만 바꿔도 1위 조합과 결론이 바뀌었습니다. 이웃한 룩백(7개월과 8개월) 사이의 성과 차이는 신호보다 잡음일 가능성이 큽니다.
2. **순위의 예측력:** 두 가정 모두 학습-검증 순위상관이 음수였습니다. 학습 순위로 조합을 고르는 방식이 미래 성과를 예측하지 못했습니다.
3. **채택 판단:** AI 챌린지에서 정해 둔 채택 기준(부트스트랩 80% 이상 우세)을 적용했습니다. 익일 체결 1위는 독립 재추출(82%)로는 통과하지만, 시계열 의존성을 반영한 블록 재추출(75%)로는 기준에 못 미쳐 채택을 보류했습니다. 이 비율은 p-value나 미래 승률이 아니라, 표본 변동을 감안한 비교입니다.

## 한계 및 개선점

- 종목 7개, 검증 48개월의 실험이라 결과를 일반화하기 어렵습니다.
- 현재 선정한 ETF를 과거에도 투자 대상으로 가정하므로 생존편향 가능성이 있습니다. 검증 결과를 본 뒤 체결 가정을 추가로 비교했기 때문에 독립적인 최종 검증 구간이 더 필요합니다.
- 표의 수치는 당시 기록 기준이며 이번 README 정리 과정에서 재실행하지 않았습니다.
- 다음 단계로는 워크포워드 검증, 최적점 하나 대신 주변 조합의 평균 성과로 판단하기, 거래비용 민감도 분석을 생각하고 있습니다.

## 진행 과정

- **v1:** 당일 체결 가정으로 실험했고, 학습 1위가 검증에서 무너지는 결과가 나왔습니다.
- **v2 (현재 코드):** 월말 종가를 보고 같은 종가에 매매하기는 현실적으로 어렵다는 점을 반영해 익일 체결을 추가했고, 월별 자기상관을 고려해 블록 부트스트랩을 더했습니다. 그 결과 결론이 달라졌고, 이 민감도 자체를 핵심 발견으로 정리했습니다.

투자 권유가 아닌 검증 방법을 비교한 개인 실험입니다.
